\begin{abstract}
When multiple AI agents share a written memory, does the group become more reliable, or more gullible? Multi-agent systems increasingly rely on shared memory, where one agent writes a conclusion and the next reads it and builds on it. Shared memory helps groups correct mistakes, because later agents see evidence that earlier agents missed. In addition, when peers are honestly mistaken, memory delivers corrections and the group converges on truth. But the same mechanism that makes shared memory valuable (being influenced by peers) is what makes it dangerous. When peers persistently write confident false entries, the memory creates a one-sided public history that appears to represent consensus. We study this using groups of six LLM agents under shared memory, live debate, and personal-memory controls, across seven models from four providers and tasks ranging from scientific claims to mathematical reasoning. Through shared memory, 43\% of non-adversarial agents adopt the false belief on the primary topic, with contagion in 26/30 pooled evaluations. When agents reason alone, none adopt it. Live debate often helps, although its success depends on the model. The effect remains when we remove the prompt language that might make agents easy to persuade. It also grows as more agents repeat the false claim. We test several defenses. A correct signal from an external verifier stops the spread in all five models tested on the primary topic. Other defenses are less reliable. These results show how shared memory can turn repeated false reports into apparent consensus. We release Agent Society and the full traces for further study.
\end{abstract}

% ============================================================
\section{Introduction}
\label{sec:intro}
% ============================================================

When AI agents work together, they typically share what they learn through a common memory. For example, one agent writes a conclusion, and the next reads it and builds on it. This pattern appears in memory-augmented multi-agent systems \citep{park2023, cuadros2026}, agentic workflows, and research pipelines. \citet{hammond2025} identify persistent shared state as a key source of multi-agent risk, and \citet{dash2026} show that memory designs which improve agent performance also expand the memory poisoning attack surface. But what happens when the shared memory contains confident false information? Does the group catch the error or adopt it?

Prior work on misinformation in LLM agents has emphasized debate, where agents challenge one another \citep{bertalanic2026, wan2026, becker2026}. The shared-memory setting, where one agent writes and later agents retrieve entries without direct reply, has received less attention despite its use in agentic workflows. We compare matched instances of the complete shared-memory, debate, and personal-memory protocols. We do not claim to isolate a single primitive such as synchrony or call count.

In each experiment, 6 agents analyze a question. They communicate in one of two formats: shared memory, where agents take turns writing to and retrieving from a common pool but cannot reply to a specific entry, or live debate, where agents can challenge earlier messages. We also run a personal-memory control, where each agent sees only its own prior reasoning. Tasks range from well-known facts (does MMR cause autism?) to screened numeric problems the model cannot answer without the supplied context. Within matched comparisons we hold agents, evidence access, model, claim, and order schedule constant and vary the complete communication protocol.

We built a testbed called Agent Society and ran more than 9,000 traced evaluations across 7 models from 4 providers. In the primary experiment, 6 LLM agents analyze a scientific claim. Four agents are instructed to persistently endorse a false belief. We hold agent configurations, evidence access, claims, model, and order schedule fixed within matched comparisons and change the communication protocol. Through shared memory, 43\% of target agents adopt the wrong answer on the primary topic (contagion in 26 of 30 pooled evaluations). In personal memory, 0\% do. In debate, adoption drops, partly because the adversaries themselves abandon their assigned position under argument pressure. In shared memory, the target role agreed because others agreed. In a separate matched debate evaluation, the same configured role rejected because the evidence was weak. Shared memory also helps correct honest mistakes, reducing the fraction of agents holding a wrong belief from 0.167 to 0.087, and this positive impact of sharing would be lost if sharing were disabled entirely. These results match predictions from information cascade theory \citep{anderson1997}, where agents rationally defer to a one-sided public history instead of reasoning from their own information.

We make three contributions.
\begin{enumerate}[leftmargin=*]
\item A controlled three-way comparison of shared memory, debate, and personal memory for false-belief spread. Prior work studies these formats separately. We run the same agents, same claims, and same false information through all three and show that changing the communication format to shared memory leads to the spread of false belief and information cascade.
\item Identification of three factors associated with stronger spread in our evaluated configurations: shared persistent state, high-confidence persistent sources, and weak personal/no-context task performance. The current design does not establish each factor as universally necessary.
\item A comparison of 11 intervention and communication configurations. An oracle claim-verification signal and timed corrections eliminate target-agent adoption for Claude Haiku. Warnings and memory limits only reduce it. Debate and topology effects vary by model and configuration.
\end{enumerate}
We release Agent Society, a paper-facing run manifest, and the configurations and traces for all reported evaluations.

\section{Related Work}
\label{sec:related}
% ============================================================

We situate our work in four areas.

\textbf{Information cascades.} \citet{anderson1997} and \citet{bikhchandani1992} established that sequential agents observing a public history can rationally ignore their private signals once the history is sufficiently one-sided. Our shared-memory setting maps onto this model. Memory entries are the public history, the model's own reasoning is the private signal, and debate forces agents to reveal reasoning instead of just conclusions. Four of six predictions match cleanly. Two are partially confirmed with model-dependent exceptions (Section~\ref{sec:discussion}).

\textbf{Multi-agent safety.} \citet{hammond2025} identify information asymmetries as key risks in multi-agent systems but do not empirically test memory format. \citet{becker2026} seed misinformation into debate and find persistence depends on group composition. Under matched rosters, we show that outcomes differ sharply across complete communication protocols. \citet{dash2026} systematically study memory poisoning in single-agent systems and show that memory designs which improve performance also expand the attack surface. We extend this to multi-agent shared memory, where one poisoned entry reaches $N$ readers. \citet{li2026constraint} show constraints weaken across memory and delegation. \citet{margalit2026} formalize governed shared memory with provenance tracking and scoped retrieval. \citet{yan2026truth} show that false evidence gains collective influence through adoption and propagation by other agents, complementing our finding that shared memory amplifies this effect.

\textbf{Conformity.} \citet{bertalanic2026} report 85.5\% sycophantic conformity on GSM-Hard with 7--8B models. We find conformity is both model-dependent (Claude Haiku: 0/25, Llama 8B: 6/9 in a separate three-problem blind cohort) and protocol-dependent (shared memory produces higher target adoption than debate for every model in the matched six-model grid). \citet{wan2026} show debate loses critical facts as positions converge, and we show that communication protocols can differ sharply in whether target agents adopt a false claim. \citet{han2026} study topology effects; our topology results are more modest than the shared-memory-versus-debate differences in the evaluated configurations. \citet{el2026} model LLM communities with Ising dynamics but treat all communication as equivalent. Our data identifies communication design as an empirical moderator of the resulting regime. \citet{du2023} show debate improves factuality in cooperative settings without adversarial agents. \citet{ann2026interaction} show interaction erases solution diversity, and we show it can amplify bad consensus. \citet{ys2026} study public conformity despite private disagreement.

\textbf{Hidden profiles.} \citet{stasser1985} established that human groups discuss shared information before unique information. \citet{li2025hiddenbench} replicate this in LLM groups and find scaling does not fix it. \citet{zhang2026silo} and \citet{zhu2025multiagentbench} benchmark distributed coordination with different topologies. Shared memory goes beyond failing to pool information. It manufactures false certainty, converting ``I don't know'' (0.20) into ``I'm 89\% sure'' (0.89) of the wrong answer.

\textbf{What we add.} \citet{becker2026} seed misinformation into debate but do not test shared memory. We directly compare shared memory with debate and personal memory. \citet{bertalanic2026} compare isolated and debate settings but do not test asynchronous shared memory. \citet{wan2026} study debate losing facts but do not compare against a non-debate channel. We run matched three-protocol evaluations, observe shared-memory target adoption across seven models (six also evaluated in debate), and show that even a specialist role can fall on questions the model cannot answer alone. Across the intervention suite, an oracle claim-verification signal is the most consistent defense, while debate, topology, warnings, and memory policies have model- or configuration-dependent effects.

\section{Setup}
\label{sec:setup}
% ============================================================

\subsection{Testbed}

All experiments run on Agent Society, our testbed for multi-agent belief propagation. It supports shared memory, multi-round debate, several memory formats and chat topologies, and grids across models, scenarios, conditions, and order schedules. Every retrieval, judgment, and memory write is traced in SQLite. We release the configurations and traces. The manifest identifies the exact run IDs and exclusions. The architecture draws on \citet{park2023}.

\subsection{Agents and communication}

We place 6 agents in a group. Each evaluates a scientific claim over 18 steps. Four agents know the correct answer but are instructed to persistently endorse the false claim. The original roster also has a skeptical specialist and a regular agent. Public labels do not reveal these roles. Agents return a stance, confidence, short reason, and cited sources in structured JSON. Full prompts and parameters appear in Appendix~\ref{app:configs}.

In shared memory, agents act sequentially and retrieve up to six recent entries. They cannot reply to a specific entry. In live debate, all agents speak in three rounds and can challenge earlier messages. In personal memory, each agent reads only its own entries. Matched comparisons hold agents, evidence access, claims, model, and order schedule fixed. The protocols still differ in timing, participation, persistence, retrieval, and reply structure, so we estimate the effect of each complete protocol. Appendix~\ref{app:channels} gives the implementation details.

\subsection{Tasks}

We test four task categories: six familiar-science topics, five computable GSM8K problems \citep{gsm8k}, five GSM-Hard problems \citep{gsmhard}, and scientific table calculations from SciTaT \citep{scitat2025}. Personal memory measures whether a model rejects the false claim without peer entries. The SciTaT expansion retains 18 of 30 candidate items using an operational screen: 0\% no-context accuracy and at least 80\% full-context accuracy. Appendix~\ref{app:tasks} describes all tasks, and Appendix~\ref{app:scitat_screen} reports the screen and model-specific baselines.

\subsection{Metrics}

We call final endorsement of the false claim by a non-adversarial agent \textit{adoption}, and a positive adoption event \textit{contagion}, borrowing the latter term from epidemiology. Unless a trajectory is explicitly discussed, both terms refer to the final recorded response rather than a transient endorsement. They are operational outcomes, not claims that an agent has a persistent internal belief beyond its generated response. ``Adversary'' means an agent assigned the scripted persistent-false-position role. ``Liar'' is shorthand for that assignment, not an inference about model intent. ``Target'' or ``non-adversarial'' means every other agent, whether its final stance is reject or uncertain. We prefer this observable role label to ``honest agent.'' The honest-mistake experiments contain no adversaries and are analyzed separately.

The experimental unit is one completed scenario--condition--roster--model--schedule evaluation, which we call a \textit{run} or \textit{cell}. Final metrics use each agent's last recorded stance on the false claim. \texttt{Uncertain} never counts as endorsement. Unless stated otherwise, table entries are unweighted means over completed cells. $n$ is the number of cells, with no imputation for failed or incomplete cells. Reuse of an order schedule in a different configuration is a separate evaluation but not a new unique schedule.

\textbf{False endorsement rate (FE).} The fraction of \emph{all} agents, including instructed adversaries, endorsing the false claim at the final step. If all 4 adversaries in a 6-agent run comply, their contribution alone is $4/6 = 0.667$. This is a reference level, not a universal statistical floor: in debate, adversaries may recant while target agents endorse. Consequently, all-agent FE cannot by itself identify spread.

\textbf{Target-agent false endorsement rate (FE$_\text{t}$).} The fraction of non-adversarial agents who endorse the false claim. This is the primary metric for whether false beliefs spread beyond the scripted sources. With 2 non-adversarial agents and 4 adversaries, FE$_\text{t} = 0.50$ means 1 of 2 non-adversarial agents endorsed. Primary spread comparisons use FE$_\text{t}$. We retain all-agent FE where source compliance or comparison with legacy runs is relevant.

\textbf{Adversary retention rate (AR).} The fraction of instructed adversaries still endorsing at the final step. If $p_A$ is the assigned adversary fraction, then $\mathrm{FE}=p_A\mathrm{AR}+(1-p_A)\mathrm{FE}_{\mathrm{t}}$. We use this decomposition whenever debate causes adversaries to abandon their assigned stance. We never recover FE$_\text{t}$ from an assumed $0.667$ floor. It is computed from agent identities and final states.

\textbf{Matched protocol adoption gap ($\Delta$FE$_\text{t}$).} For matched scenario--roster--model--schedule cells, we subtract personal-memory FE$_\text{t}$ from the communication protocol's FE$_\text{t}$. This separates target adoption associated with peer communication from a model's tendency to endorse even when alone. It is especially important on SciTaT, where some models have nonzero personal baselines. The gap estimates the effect of the full protocol bundle, not a single mechanism.

\textbf{Contagion rate.} The fraction of completed cells in which at least one non-adversarial agent endorses at the final step, equivalently $\mathbf{1}[\mathrm{FE}_{\mathrm{t}}>0]$ per cell. We report the numerator and denominator (e.g., 5/5). Because this any-target event depends on the number of target agents, adversary-ratio comparisons use mean FE$_\text{t}$ as the primary outcome.

Condition-level FE and FE$_\text{t}$ values are macro-averages of cell-level fractions. Pooled evaluations are descriptive unless labeled as matched pairs. Order schedules are controlled robustness variations, so we report exact counts and finite-grid means rather than population-level significance tests. Appendix~\ref{app:metrics} defines secondary and trajectory metrics.

\subsection{Models}

Seven models from 4 providers. Gemma 3 4B (Google), Llama 3.1 8B (Meta), Mistral 8B, GPT-4o-mini (OpenAI), Claude Haiku 4.5, Claude Sonnet 4.6, and Claude Opus 4.6 (Anthropic). All at temperature 0. Gemma was tested in shared memory only (no debate runs).

\section{Sharing Corrects Honest Mistakes}
\label{sec:honest}
% ============================================================

Before testing deliberate deception, we tested honest mistakes. One agent starts wrong but is free to update. Across four familiar-science topics and 10 schedules per condition, personal-memory FE is 0.167 and shared-memory FE is 0.087. An oracle claim-verification signal reduces it to 0.013. These values include all agents because this experiment has no adversaries.

Correction works better when it arrives early. When the mistaken source leaves before correction, shared-memory FE is 0.158, but its error never spreads in 160 source-exit cells. Debate reduces source-exit FE to 0.008 by exposing the agent to counterarguments before it leaves. Appendix~\ref{app:honest} reports the full timing and exit results.

Trace inspection shows the target agent treating repeated one-sided entries as peer consensus. The same configured role cites replication evidence in personal memory. Debate permits direct challenge, and some Haiku adversaries recant. These generated explanations support the behavioral interpretation but do not reveal the model's internal causal process. Full trajectories appear in Appendix~\ref{app:traces}.

The matched neutral-prompt replication uses the same 10 schedules under all three protocols. Shared-memory FE$_\text{t}$ is 0.900, while debate and personal-memory FE$_\text{t}$ are both 0.000 (Appendix~\ref{app:neutral_prompt}).

\subsection{What makes contagion stronger or weaker}

With neutral target-agent prompts, mean FE$_\text{t}$ scales from 0.000 at 1/6 adversaries to 0.475 at 2/6 and 1.000 at both 3/6 and 4/6 (Appendix, Table~\ref{tab:adversary_ratio}). Debate and personal memory remain at FE$_\text{t}=0$ throughout. At a 50/50 split, the adversaries write persistently at high confidence while target agents lack a comparably persistent counter-signal. We compare ratios using FE$_\text{t}$ rather than all-agent FE because the scripted adversary fraction, and therefore the all-agent reference level, changes by design.

Longer exposure is associated with more contagion: 1/5 after one step and 4/5 after twelve (Appendix, Table~\ref{tab:app_exit}). At a 3:3 ratio, the high-confidence persistent condition produces 80\% contagion, while a mild condition changing confidence and persistence together produces 0\%. This comparison identifies the full manipulation rather than either feature alone.

The deliberate-lie experiments withhold evidence cards. Personal-memory target agents still reject the false claim using training knowledge, while shared-memory target agents sometimes adopt after reading peer entries. This isolates peer communication relative to the matched personal baseline. It does not test how external counter-evidence changes the effect.

\subsection{When the model cannot get it right alone, even the expert falls}

For the primary Haiku ambiguity grid, contagion ranges from 0/5 on MMR to 5/5 on ego depletion. PANDAS is 4/5, LK-99 3/5, STAP 2/5, and climate 1/5 (Appendix, Table~\ref{tab:app_ambiguity}). GSM8K remains 0/25 when agents can compute the answer. In the original two-item Haiku SciTaT study, contagion is 10/10 and the specialist role also endorses. These are task- and model-specific empirical gradients, not a calibrated universal ambiguity scale.

In the expanded 18-item study (810 completed cells), shared-memory FE$_\text{t}$ is 0.917 for Haiku, 0.856 for Mistral, and 0.739 for Llama. Because personal-memory FE$_\text{t}$ is 0.000, 0.389, and 0.556 respectively, the matched shared-minus-personal adoption gaps are 0.917, 0.467, and 0.183. Debate FE$_\text{t}$ is 0 across all 270 debate cells (Appendix~\ref{app:scitat_screen}).

We tested 11 intervention and communication configurations. Table~\ref{tab:mitigations} shows the directly comparable ego-depletion subset.

The oracle condition gives each agent a claim-level message from a correct external verifier. It yields zero target adoption in 5/5 Haiku cells. In the cross-model grid, it also yields FE$_\text{t}=0$ for all five evaluated models on ego depletion (25 cells, Appendix~\ref{app:crossmodel_mitigations}). This is a scoped upper bound that assumes access to a correct verifier. Debate yields zero adoption for Claude Haiku but not for all models. Both early and late corrections yield zero adoption in the five evaluated Haiku schedules.

An independence-aware memory format that warns that entries are not independent reduces contagion from 5/5 to 2/5 in this Haiku comparison (all-agent FE 0.833 to 0.733). Because it also changes retrieval presentation, it is a bundled intervention. Fading old entries reduces contagion to 4/5 but also weakens older correct entries. Forcing the specialist to write does not reduce the 5/5 rate. Opus likewise shows 5/5 under the evaluated baseline, so moving to that larger model alone does not protect this setup.

\section{Discussion}
\label{sec:discussion}
% ============================================================

Shared memory corrects honest mistakes in our experiments, reducing FE from 0.167 to 0.087. It also amplifies persistent false entries, producing FE$_\text{t}=0.433$ on ego depletion. Repeated one-sided reports can look like independent agreement even when later entries inherit the same claim. A useful memory system must preserve correction while exposing source dependence.

The pattern is consistent with information cascades \citep{anderson1997}. A model's own answer competes with the public history in memory. Adoption grows when the private answer is weak, exposure is longer, or false reports are persistent. It falls when the answer can be independently computed or a reliable correction enters the record. Appendix~\ref{app:cascade} gives the complete prediction mapping and exceptions.

Prompted persistence is an experimental stress test. It does not show how deception arises naturally. The neutral roster removes susceptibility language and produces higher shared-memory adoption (FE$_\text{t}=0.900$ versus 0.500, $n=10$ each). It also removes the specialist role and changes the write threshold, so it tests the full roster package. The susceptibility phrase is not required for adoption.

Shared memory and debate are complete protocol bundles. They differ in timing, participation, persistence, retrieval, and direct reply. Debate outcomes also reflect both target resistance and adversary recanting. We therefore make protocol-level comparisons. Results may change with future models, schedules, free-text outputs, and naturally emerging disagreement. Oracle verification succeeds across the five models tested here, while debate and topology remain model-dependent.

% ============================================================
\section{Conclusion}
\label{sec:conclusion}
% ============================================================

Shared persistent state in multi-agent LLM systems produces measurable false-belief adoption among target agents. In shared memory, 43\% of target agents adopt the false claim on ego depletion (contagion in 26/30 pooled evaluations, 0\% in personal memory). Target-agent adoption occurs in shared memory for all seven evaluated models. Debate was evaluated for six, and its protection is model-dependent. Debate outcomes reflect both target-agent resistance and adversaries abandoning their assigned position. The same mechanism that makes shared memory valuable for correcting honest errors makes it dangerous for amplifying persistent false entries. An oracle claim-verification signal eliminates target-agent adoption on all five models in the cross-model mitigation study. Debate and corrections also eliminate it on Claude Haiku, while warning and memory-limit interventions provide partial or inconsistent reductions. A neutral-prompt replication confirms that susceptibility language is not necessary, although it changes the full target-agent roster rather than one phrase alone. Whether the same rates hold with naturally emergent disagreement remains an open question.

\subsection*{Ethics Statement}
This work studies false-belief propagation in AI systems. No human subjects are involved. The scientific claims used as scenarios are from published literature. We do not release attack tools. The testbed is for defensive safety evaluation. The finding that shared memory can spread false beliefs, including vaccine misinformation in some models, has dual-use potential. We report it because the vulnerability exists in deployed systems and defenders need to know.
